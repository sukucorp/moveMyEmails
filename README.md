**moveMyEmails**: Move emails between two folders - internal or cross-server

    positional arguments:
      config_file         Path to the YAML configuration file containing your operations.

    options:
      -h, --help          show this help message and exit
      --sample FILE_PATH  Generate a sample YAML file containing both move templates and exit.
      --dry-run           Simulate the job execution without modifying any mailboxes.
      --validate-config   Validate the configuration syntax and logic without running jobs.
